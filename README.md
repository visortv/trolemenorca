# Menorca Bus V12.16

Aplicación web de horarios de transporte regular de Menorca.

Operadores incluidos: TMSA, Bus Torres y Autos Fornells.

La publicación de Render conserva por compatibilidad el comando histórico `sync_tmsa.py`; desde V12.16 ese bootstrap instala el runtime completo y sincroniza inteligentemente los tres operadores.
